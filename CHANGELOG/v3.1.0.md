# v3.1.0

> 2026-11-04

### 新增

- ✨ 适配 `nonebot-plugin-htmlrender` 0.8，同时兼容 0.6 / 0.7
- ✨ 模板的样式、字体、头像全部内联成 data URI，不再依赖 htmlrender 的本地文件访问权限

### 修复

- 🐛 修复统计 SQL 的笛卡尔积问题：场景过滤没有 join 到会话表，导致榜单混入其他群、甚至 bot 已退出群里的人
- 🐛 修复用户映射错位，改为按 `user_persist_id` 精确映射
- 🧹 清理无用依赖（cesaa、apscheduler、localstore）

### 升级提示

用 htmlrender 0.8 时需要在 `.env` 里加 `RENDER__PROVIDER=playwright`（3.4.0 起会自动补）。

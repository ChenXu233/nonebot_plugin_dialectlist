# v3.5.0

> 2026-11-05

### 新增

- ✨ 多套样式：暗夜 / 浅色 / 简约 / 暖阳，换样式不用动模板
- ✨ 样式按目录组织（`themes/<名字>/` + `meta.json`），丢进去自动注册，不用改代码
- ✨ 榜单 / 分布图 / 多群对比 / 成员跨群共用同一套外壳，换一次样式所有图一起变
- ✨ 样式缺哪部分就回落到默认（暗夜）：只写 `base.css` 也能出全套图
- ✨ 两种排版：竖排（默认）和横排，人多时一眼看全
- ✨ 模板包：模板从单个 `.j2` 变成目录，支持 `meta.json` 和 `extra.css`，放进配置目录就能用
- ✨ 内置第二套模板 `podium`：前三名上台，其余收成紧凑列表
- ✨ 新增指令 `/B话榜帮助`（`/B话榜 帮助` 也行），一次看全所有用法
- ✨ 新增指令 `/B话榜样式`、`/B话榜模板`，先预览再决定用哪个
- ✨ `B话榜` 支持 `-m/--template`，就这一次换模板
- ✨ 分布图：`/B话榜分布 [时间] [小时|星期]`，看群里几点最热闹
- ✨ 多群对比：`/B话榜对比 群号 群号 …`，几个群放进一张图
- ✨ 成员跨群：`/B话榜成员 @某人`，看 TA 在各个群说了多少

### 修复

- 🐛 定时推送一直拿不到昵称和头像（把持久化 id 当成平台号去查了），多群对比同样受益

### 性能

- ⚡ 内置字体改成 GB2312 一级常用字子集，单张图少传约 5MB，出图耗时约减半
- ⚡ 头像下载复用连接池并按 URL 缓存，失败重试从 9 秒降到 3 秒，坏链不再拖住整条命令
- ⚡ 用户信息缓存默认开启，同一条榜单不再重复请求用户资料

### 变更

- ♻️ 模板、样式、排版彻底拆开：`template`（结构）+ `theme`（样式）+ `layout`（排版），一种图对应一套结构 css + 样式目录里同名的额外 css
- ♻️ `template_path` 的中文键改名 `模板路径`，`模板` 现在指模板名；老写法继续兼容
- ♻️ CSS 里的字体和图片统一内联成 data URI，模板目录自带 `res/` 也能用

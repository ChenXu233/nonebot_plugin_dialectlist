# v3.5.2

> 2026-11-06

### 新增

- ✨ 榜单显示和上一期比的名次变化：`↑2` / `↓1` / `新`，默认开启，`/B话榜配置 环比 关` 或 `dialectlist__show_delta=false` 可以关掉
- ✨ 多群对比图也带环比，每个群按自己的配置单独算
- ✨ 定时推送不再写死 QQ 群：开启推送时记录当前会话的 SAA 发送目标，Telegram / Discord / 飞书等平台也能推送

### 变更

- ♻️ 上一期区间跟着查询走：今日对比昨日同时段、本周对比上周、本月对比上月同日、年度对比去年；自定义区间按同样长度往前挪一段
- ♻️ 文字榜单支持 `{delta}` 占位符，想显示变化就自己加进 `dialectlist__string_format`
- ♻️ 群人数下限检查只对 QQ 群生效，其他平台直接跳过，不再白问一次接口

### 修复

- 🐛 `/历史B话榜` 不再追问起止日期，按 README 写的全量历史统计
